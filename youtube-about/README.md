# موقع تعريفي عن يوتيوب

صفحة عربية RTL، مستقلة وغير رسمية، تعرف بمنصة الفيديو وبعض صيغ المشاهدة وأدوات المبدعين والاكتشاف. لا تستخدم واجهة YouTube API ولا تجمع بيانات ولا تتطلب خادمًا أو مفاتيح.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم ملفات ثابتة من المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.
