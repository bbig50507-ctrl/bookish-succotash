# منصة عقارات وحجوزات — نموذج واجهة أولي

مشروع واجهة عربية لتصفّح أماكن الإقامة، صُمّم ليكون مناسبًا للهاتف. التطبيق الموجود حاليًا **نموذج واجهة أمامية تفاعلي** فقط، وليس منصة جاهزة لاستقبال حجوزات أو مدفوعات.

## ما يعمل الآن

تُعرض الصفحة من `public/index.html`. يمكن استعراض أماكن تجريبية، والبحث والتصفية حسب النوع، وحفظ المفضلة محليًا في المتصفح، وفتح نافذة التفاصيل. التصميم عربي RTL ومتجاوب مع الشاشات الصغيرة. الصور والأسعار والمواقع في النسخة الحالية توضيحية وليست عروضًا حقيقية.

## ما لم يُربط بعد

لا يحتوي المستودع حاليًا على تطبيق React أو خادم أو قاعدة بيانات أو كود Supabase. تسجيل الدخول وإرسال طلب الحجز والدفع بعملة USDT ورفع إثبات الدفع ولوحة الإدارة والتحديثات الفورية غير مفعّلة. زر الحجز معطّل عمدًا حتى إعداد backend وقواعد البيانات والصلاحيات وتدفق الدفع والتحقق منها.

لا تُدخل بيانات شخصية أو مالية في هذه النسخة، ولا تعتبر أي سعر أو مكان معروض حقيقيًا أو قابلًا للحجز.

## المعاينة محليًا

```bash
cd public
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. تشمل الأصول صورًا محلية تحت `public/assets/`، ولا تحتاج الصفحة إلى تثبيت حزم.

## الخطوة اللازمة لتشغيل الحجوزات فعليًا

قبل استقبال حجوزات أو إثباتات دفع، يجب تحديد بيئة Supabase ومخطط الجداول وسياسات RLS والأدوار وتخزين الصور وتفويض الإدارة، ثم تنفيذ واجهات الخادم ودورة مراجعة الدفع. يجب حفظ مفاتيح الخدمة في الخادم فقط وعدم وضعها داخل ملفات المتصفح. لم تُجرَ أي تغييرات على قاعدة بيانات أو إعدادات دفع ضمن هذا التحديث.

## المجلدات الأخرى

`youtube-about/` يحتوي صفحة تعريفية منفصلة عن يوتيوب، ولا تتصل بمنصة الحجوزات.
