# منصة عقارات وحجوزات — نموذج واجهة أولي

مشروع واجهة عربية لتصفّح أماكن الإقامة، صُمّم ليكون مناسبًا للهاتف. التطبيق الموجود حاليًا **نموذج واجهة أمامية تفاعلي** فقط، وليس منصة جاهزة لاستقبال حجوزات أو مدفوعات.

## ما يعمل الآن

تُعرض الصفحة من `public/index.html`. يمكن استعراض أماكن تجريبية، والبحث والتصفية حسب النوع، وحفظ المفضلة محليًا في المتصفح، وفتح نافذة التفاصيل. التصميم عربي RTL ومتجاوب مع الشاشات الصغيرة. الصور والأسعار والمواقع في النسخة الحالية توضيحية وليست عروضًا حقيقية.

## ما لم يُربط بعد

لا يحتوي المستودع على تطبيق React أو خادم متصل بالواجهة. تسجيل الدخول وإرسال طلب الحجز والدفع بعملة USDT ورفع إثبات الدفع ولوحة الإدارة والتحديثات الفورية غير مفعّلة. زر الحجز معطّل عمدًا حتى إعداد backend وقواعد البيانات والصلاحيات وتدفق الدفع والتحقق منها.

## ملفات بداية عامل Supabase (غير منشورة)

يتضمن المستودع `supabase-schema.sql` و`supabase-trigger.sql` و`.github/workflows/process-supabase-tasks-event.yml` لمراجعة الطلبات عبر Supabase وGitHub Actions وClaude. أضيفت للواجهة الآن نماذج تسجيل الدخول وإنشاء الحساب وإرسال طلب الحجز. الاتصال غير مفعّل افتراضيًا: أضف رابط Supabase ومفتاح `anon` العام فقط إلى `public/supabase-config.js` بعد إعداد قاعدة البيانات واختبار RLS. لا تضع مفتاح `service_role` في مجلد `public/`.

مشروع Supabase المرتبط حاليًا غير نشط؛ لذلك لا يمكن إرسال طلبات فعلية أو تحقق الاتصال الآن. لم تُطبّق ملفات SQL على قاعدة مستضافة. لا تضع مفاتيح سرية داخل Git أو ملفات `public/`. يجب تنفيذ تأكيد الحجز والدفع بقواعد خلفية موثوقة، لا بقرار Claude.

لا تُدخل بيانات شخصية أو مالية في هذه النسخة، ولا تعتبر أي سعر أو مكان معروض حقيقيًا أو قابلًا للحجز.

## المعاينة محليًا

```bash
cd public
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. تشمل الأصول صورًا محلية تحت `public/assets/`، ولا تحتاج الصفحة إلى تثبيت حزم.

## الخطوة اللازمة لتشغيل الحجوزات فعليًا

قبل استقبال حجوزات حقيقية: فعّل مشروع Supabase، راجع واختبر `supabase-schema.sql` و`supabase-trigger.sql` على بيئة منفصلة، أعد تهيئة RLS وسياسات المستخدمين، ثم أضف رابط المشروع ومفتاح `anon` العام إلى `public/supabase-config.js`. أضف أسرار GitHub وVault المطلوبة لتشغيل العامل، واختبر دورة المهمة. لا يتضمن المشروع دفعًا إلكترونيًا أو رفع إثبات دفع أو لوحة إدارة أو تحقق توفر/تعارض تواريخ. لم تُطبّق تغييرات قاعدة بيانات مستضافة.

## المجلدات الأخرى
